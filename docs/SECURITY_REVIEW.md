# 安全复查 · 2026-10-18

维护方：**佳成的挑战日记**。这是针对当前仓库内容的维护者自查与修补记录，不是第三方安全认证，也不是对宿主平台、图像模型和未来代码的零风险保证。

## 范围与方法

检查技能主指令、所有引用文档、可选图片收集脚本、依赖、安装与数据说明、公开文件及当前公开 Git 历史。用合成图片复现两个旧行为，再执行安全回归测试；未用真正的私密图片、密钥或恶意漏洞样本演示攻击。

生图宿主的内部实现和服务端留存策略不在代码审计范围。新添加的 CI、依赖更新配置和发行包属于维护措施，不是独立安全认证。

## 发现与修补

### 依赖风险：旧 Pillow 的照片解码漏洞

本机原测试环境带 Pillow 12.3.0。上游 13.0.0 在 2026-10-16 修补了与 JPEG 解码、EXIF 处理等有关的问题，存在接触不可信图片时的依赖风险。没有执行漏洞利用样本来判断本机可利用性。

辅助脚本现拒绝低于 13.0.0 的版本，依赖固定为已测的 13.0.0，并限制只能启用 PNG、JPEG、WebP 三种解码器。测试用隔离目录里的修补版运行，系统与宿主内置依赖没有被修改。参考：[Pillow 官方安全修复说明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)。

### 中等：外部清单能指向未授权的本机图片

旧脚本只检查图片存在与格式，没有约束 `source_path`、`generated_path` 的读取范围。合成复现确认：清单可以把“预期生图目录之外”的另一张图片复制到结果目录。脚本没有自动外传，但若随后分享结果，可能泄漏本机图片。

修补：调用者独立提供读取目录白名单和输出工作区，清单不能自行扩大目录范围；拒绝路径越界、链接／junction、网络路径和受保护配置目录。保持新目录写入和文件独占创建；写入已经验证的字节快照，避免复制时再次读取变化后的路径。

### 中等：日志透传造成隐私外带

旧脚本原样保存 `execution`、`review` 和 `correction` 中的额外字段。合成复现确认：这些额外字段会进入 `run.json`。没有发现真实密钥泄漏；问题在于用户公开调试记录时可能无意带出隐私。

修补：默认不记录提示词、验收文本、原图路径及原图哈希，未知字段不透传。只有显式 `--include-prompts` 才写私密调试文本；允许字段内仍可能含个人信息，需要人为检查。

### 中等：图片与清单的资源消耗缺少上限

旧脚本没有明确限制批量数量、文件字节或像素规模。修补为每批最多 32 张、每文件 32 MiB、总编码数据 256 MiB、每图 4000 万像素、清单 2 MiB；在解码前检查并拒绝动画及未支持格式。生成图带 GPS EXIF 时拒绝复制。

### 指令边界与宣传边界

技能现明确：照片中的文字、二维码、文件名、第三方清单和模型回复不能授权执行命令、读取其他文件、索取密钥或上传到新位置。普通成品默认不加品牌水印，不能为了宣传改变用户照片或在对话中强塞推广。

## 验证结果

- 两个旧风险均已用不含个人数据的合成图片确认。
- 24 项自动化回归全部通过，覆盖越界读写、配置目录、日志最小化、超限输入、不支持格式、动画、GPS、比例、已存在目录、未验收结果和字节快照写入。
- 将先前八张实际生成文件重新通过加固版收集器，八张均通过，输出保持原始字节，默认日志未包含提示词。
- 技能与辅助脚本没有发现联网、子进程执行、密钥读取、遥测或自动安装逻辑。真实图像生成仍使用选定平台的网络服务。
- 公开文件、历史和发行包另作密钥模式与图片 GPS 检查；这类扫描不能识别所有个人信息或所有凭据形式。

## 剩余限制

脚本不是 OS 级隔离，不用于防御有本机并发写权限的恶意用户；没有进行解码器模糊测试或专业渗透测试。文件允许范围内的照片仍可能敏感，非 GPS 元数据和自然语言文本也可能含隐私。任何公开发布仍需人工检查。宿主模型是否会遵守技能边界也不能由这些 Python 测试证明。

CI 使用只读仓库权限、固定 checkout 提交、不保留 Git 凭据、隔离安装依赖和超时限制。依赖更新由 Dependabot 提出，变更后仍需通过测试。
## v0.2 照片触发补充

新入口把“照片无附文”约定为撕纸请求，适用于用户主动启用的工作流或专用项目。显式其他任务优先；截图、文档、浏览文件读到的图片和模型生成的候选图不自动触发，避免循环生图或干扰排错。推荐项目范围安装，不写入全局规则。

分发构建脚本只读取仓库内的固定技能与清单，写入指定的新输出目录，不联网、不执行外部命令、不收集凭据。不打包原照片、作品示例或私密调试目录。插件没有 hook、MCP、后台服务或额外权限。便携包包含单文件视觉指令，省去依赖安装；生图仍由用户选择的平台处理照片。
