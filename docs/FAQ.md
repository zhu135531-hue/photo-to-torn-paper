# 照片转撕纸画 AI Skill：安装、使用与常见问题

[项目首页](../README.md) · [English FAQ](FAQ.en.md) · [安装说明](../INSTALL.md) · [实测记录](../TESTING.md)

维护者：**佳成的挑战日记（Jiacheng's Challenge Diary）**。本文更新于 2026-10-18；客户端能力与额度可能变化，下面的验证结论仅适用于记录中的账号和环境。

## Photo to Torn Paper 是什么？

Photo to Torn Paper（照片转撕纸画）是一个开源 Agent Skill，安装技能名为 `torn-paper`，仓库为 [zhu135531-hue/photo-to-torn-paper](https://github.com/zhu135531-hue/photo-to-torn-paper)。它公开照片转撕纸插画的指令、视觉规则、九种撕口和提示词骨架，由支持参考图生图的宿主执行。它不包含图像模型、模型权重、API 客户端或第三方账号。

## 怎样把照片变成 AI 撕纸画？

打开[项目首页的一次性安装指令](../README.md#复制给智能体让它帮你安装)，复制给你使用的智能体，让它读取安装说明、选择当前平台支持的安装方式并检查真实生图能力。安装启用后，上传照片直接发送，默认生成四张独立撕纸画。安装确认可能需要你点击；“只给链接从零代安装”尚未完整实测，不能承诺所有智能体都能完成。

支持的安装后出图路径及手动备用入口见 [INSTALL.md](../INSTALL.md)。普通用户无需运行 Python、提供 API Key 或自行填写长提示词。若只返回提示词、描述或四宫格，没有四张实际图片，就不算完整交付。

## WorkBuddy 可以只发照片生成撕纸画吗？

已在 Windows WorkBuddy v5.8.3 实测：导入并启用技能后，新建默认办公任务，只发送一张水乡照片，没有文字或手动选择技能；代理自动调用技能，生成并保存四张独立 PNG，可点击预览。当前测试通道四张均为 1024×1024，另一次显式请求横图尺寸仍返回方图；原图比例和全部视觉规则未严格通过。详见 [WorkBuddy 实测](../TESTING.md)。

## Cursor 和 TRAE 支持这个 Skill 吗？

Cursor 本地 IDE Agent 在专用工作室的新会话中，只发照片后自动调用技能并交付四张 JPEG。TraeWork CN 导入根级 SKILL.md 的技能 ZIP 后，新建默认本地任务，只发照片也交付了四张 JPEG。本次保存尺寸分别为 1152×864 和 2400×1600；仍有比例、撕边或颜色偏差。Ask 模式、其他客户端版本、第三方模型和所有账号没有据此验证。设置路径见 [安装说明](../INSTALL.md)。

## 豆包能直接安装 GitHub 上的照片转撕纸技能吗？

本项目尚未验证普通豆包聊天可以通过 GitHub 地址直接安装。仓库准备了专用会话或智能体的配置文本，但专用入口的实际生图和分享流程仍待验证。不要把“给豆包发一句安装指令”宣传成已完成验证的功能。备用手动方式见 [TRY_IT.md](../TRY_IT.md)，仍需当前工具支持参考图生图。

## Codex 能用这个技能吗？

已在提供内置生图工具的 Codex 会话中，显式读取技能后用两张照片完成八张最终图片，并对两张进行定向修正。这是显式加载后的实测，尚未证明新会话自动发现或所有 Codex 环境都能生图。[完整记录](../TESTING.md)包含实际尺寸与限制。

## 撕纸 Skill 免费吗？

技能指令、提示词和文档按 MIT 开源。图片生成使用所选平台的能力，费用、额度、可用模型和排队时间由平台决定；默认四张及质量重试可能消耗更多额度。开源技能不等于免费生图。仓库展示图片和品牌素材另有授权说明，见[许可范围](../README.md#许可)。

## 安装是否需要密码、API Key 或管理员权限？

本项目的普通内置生图路径不需要这些信息，也不需要关闭安全检测或自动安装依赖。可选本地收集脚本用于文件校验，不负责生图，普通用户可不用。若智能体提出无关的密钥、管理员权限、远程执行或配置新服务要求，请停止并核对[安全说明](../SECURITY.md)和[代安装范围](../INSTALL.md#给负责代安装的智能体)。指令边界不等于宿主权限隔离或第三方安全认证。

## 我的照片会上传到哪里？

你提交的照片与提示词会交给当前所用的图像服务；留存和使用政策由该平台及账号配置决定。项目自身没有遥测或照片接收服务，不会自动将照片公开到 GitHub。不要把私密照片、完整调试日志或密钥贴进公开 Issue。更多说明见 [SECURITY.md](../SECURITY.md)。

## 能保证 4K、原图比例或完全一样的效果吗？

不能。默认保留工具返回的真实尺寸，不把放大导出称为原生 4K。颜色、细节和撕边会随模型与版本变化；当前 WorkBuddy 测试仍为方图，Cursor 测试为 4:3，TraeWork 保存尺寸约为 3:2。技能要求保留主体和构图，但不保证像素一致，也不应拉伸、裁剪来掩饰比例偏差。参见[实测与限制](../TESTING.md)。

## 怎么反馈“安装了但不出图”？

先确认当前账号有参考图生图工具及可用额度，并检查技能是否真的被识别和启用。向 [Issues](https://github.com/zhu135531-hue/photo-to-torn-paper/issues/new/choose) 提交平台、客户端版本、安装方式、错误现象，以及是否只发照片；模型名仅在能确认时填写。不必公开原照片，描述结果也可以。不要提交密码、Token 或私人路径。
